# История редакций

## 2026-10-26 — GPT-6.1 Terra

- Добавлена официально объявленная GPT-6.1 Terra: назначение, доступ в desktop, минимальная версия CLI, идентификатор и ограничения.
- Добавлен теоретический разбор сравнения BI-скриншотов; существующий визуальный сценарий дополнен ссылкой без создания повторного кейса.
- Снимки официальных источников зарегистрированы отдельно от исторической сверки 24 октября. Модельные запросы и установка обновлений не выполнялись.

## 2026-10-24 — практическое использование из AI-радара

- Добавлен отдельный блок из семи сценариев: визуальная проверка, Figma, Colormason, презентации, исследование конкурентов, Archify и деловая процедура как skill.
- Для каждого сценария даны промпт, проверяемый результат, пояснение для Windows и вариант изучения без запуска.
- Разделены официальные возможности, сторонние инструменты и учебные адаптации. Уточнено, что текущий Codex Slides экспортирует PPTX со слайдами-изображениями.
- Повторы новостей и организации чатов заменены ссылками на существующие объяснения; описан порядок дальнейшего отбора.
- Сведения о сопровождении сайта приведены в соответствие с настроенной ежедневной проверкой в 21:00 Europe/Berlin.

## 2026-10-24 — поиск по кириллице

- Исправлена обработка русских поисковых запросов в индексе темы; сохранён поиск по английским терминам.

- Добавлен проверенный срез новинок, включая CLI 0.164.0 от 23 октября и Composer Predictions с ограничениями beta.

- Добавлены сценарии для самостоятельного чтения и пример из реальной подготовки руководства.
