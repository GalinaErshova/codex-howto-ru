# История редакций

## 2026-10-24 — поиск по кириллице

- Исправлена обработка русских поисковых запросов в индексе темы; сохранён поиск по английским терминам.
- Совпадения и префиксы поддерживаются без обещания русского морфологического поиска.

## 2026-10-24 — новые возможности и сценарии

- Добавлены инструкции по `/side`, `/fork`, проектным чатам, поиску и ссылкам на Windows.
- Разделены боковой чат, развилка переписки, отдельный worktree и связанные результаты проекта.
- Добавлен проверенный срез новинок, включая CLI 0.164.0 от 23 октября и Composer Predictions с ограничениями beta.
- Публикации Tibo отделены от подтверждений документацией; недоступные X-посты не выдаются за прочитанные источники.
- Добавлены сценарии для самостоятельного чтения и пример из реальной подготовки руководства.

## 2026-10-24 — сайт GitHub Pages

- Отдельный сайт для чтения без Git и установленного Codex.
- Меню модулей, маршрут чтения без практики, поиск и мобильная навигация.
- Сайт собирается из существующих Markdown-файлов; копии учебного текста не создаются.
- Тема Just the Docs закреплена на версии v0.12.0.
