# Адрес сайта и перенос

Целевой адрес руководства: **https://codex.galaershova.ru/**. Репозиторий остаётся [GalinaErshova/codex-howto-ru](https://github.com/GalinaErshova/codex-howto-ru). Поддомен не требует переименования репозитория или переноса исходников.

## Настройки

- GitHub Pages публикует ветку `main`, папку `/`.
- `CNAME` содержит ровно `codex.galaershova.ru`.
- В `_config.yml`: `url: https://codex.galaershova.ru`, `baseurl: ''`.
- DNS: запись типа **CNAME**, имя **codex**, значение **galinaershova.github.io**. Имя репозитория, `https://` и путь в значение DNS не входят.

## Порядок переключения

Изменения этого переноса объединяют только при готовом доступе к DNS. Сначала привязывают поддомен в GitHub Pages через публикацию `CNAME`, затем включают соответствующую запись у DNS-провайдера. До переключения не следует считать новый адрес рабочим. Текущий проверенный адрес и статус публикации указаны в PR переноса.

После обновления DNS проверяют GitHub Pages domain check, выпуск сертификата и Enforce HTTPS. До готовности сертификата HTTPS на новом адресе может не работать. По документации GitHub обновление DNS и доступность HTTPS могут занять до 24 часов. [Официальный порядок GitHub](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

## Приёмка

1. Новый адрес отвечает по HTTPS без предупреждения браузера.
2. Стили, поиск и меню загружаются от корня домена, без прежнего префикса `/codex-howto-ru`.
3. Открываются модули, новости, практикум и страница условий использования; внутренние якоря работают.
4. Старый адрес GitHub Pages и прежняя глубокая ссылка проверены на переход к соответствующей странице нового домена. Перенаправление проверяют фактически, а не обещают до настройки.

Не удаляйте DNS или привязку Pages несогласованно. При откате восстановите рабочие `url` и `baseurl` вместе с настройками домена и повторите проверку старого адреса. Доменные и серверные изменения не подтверждают установку счётчика посещаемости: Метрика подключается отдельно после получения номера счётчика.
