# Проверки русской редакции Codex на Windows

Дата: **24 октября 2026 года**, Europe/Berlin.

## Что выполнено

- Прочитаны 14 upstream-модулей на коммите `65e9712af333bea85f20030ed2b33b51308a228e`; сохранена оригинальная MIT-лицензия.
- Продуктовые положения сверены по текущим официальным страницам OpenAI. Снимки основных источников и их SHA-256 зарегистрированы в [`sources-manifest.json`](../sources-manifest.json). Проверка доступности 27 официальных адресов вернула HTTP 200, включая редиректы. Доступность страницы сама по себе не доказывает соответствия всех утверждений — смысловая сверка выполнялась отдельно.
- Два помощника независимо проверили подготовленные ими разные части руководства и затем провели перекрёстную вычитку. Найденные проблемы перехода в папку и выбора Python исправлены. Это редакционная проверка материала, а не запуск всех описанных интеграций.
- **27 блоков PowerShell** прошли синтаксический разбор в Windows PowerShell **5.1.26100.9711** и PowerShell **7.6.5**. Блоки не выполнялись целиком. Разбор синтаксиса не доказывает наличие программ, доступ к сети или успешный ответ модели.
- Пример TOML custom agent разобран стандартным Python `tomllib`.
- На отдельной рабочей копии исходного учебного backend выполнены **2 теста unittest**, оба прошли. Воспроизведено `reserve(5, -1) = 6`; дефект специально оставлен как упражнение читателю.
- Локально проверены операции создания и копирования каталогов с пробелами, кириллицей и квадратными скобками, а также сохранение и чтение UTF-8 через .NET.
- Справочные вызовы `codex --version`, `codex --help`, `codex exec --help`, `codex mcp --help` проверены на установленном CLI **0.144.5**. В этой установке есть npm-обёртка `codex.cmd`. В среде Codex были предупреждения о правах на временные PATH aliases; help и version завершились успешно. Пользовательские настройки не изменялись.
- Автономный HTML открыт в Chrome при ширине **1440** и **390 px**. Внутренние переходы проверены, горизонтального переполнения страницы нет. Таблицы и код прокручиваются внутри своих блоков. Просмотрены скриншоты начала и практикума; мобильное оглавление раскрывается.
- Локальные файловые ссылки и наличие всех 14 модулей проверены автоматически. Во всех модулях есть упражнение, критерий готовности, самопроверка и переход к теоретическому разбору. В HTML нет внешних скриптов, шрифтов и стилей: основной текст доступен без сети.
- Добавлен отдельный маршрут чтения: **14 русских ситуаций с вопросами и объяснениями**. Они доступны внутри полного руководства и отдельным Markdown-файлом. Для чтения не нужны установленный Codex, терминал или обращения к модели.

## Что не выполнялось

Установка и обновление программ, изменение глобальной конфигурации, авторизация, подключение серверов MCP, выполнение пользовательских модельных запросов из примеров, запуск hooks, настройка расписаний, облачных задач или публикация. Практикум не проходился за читателя: проверены исходник и исходное ошибочное поведение.

Внешние якоря внутри официальных страниц не проверялись автоматически. Интерфейс настольного приложения и доступность возможностей конкретному аккаунту не подтверждаются проверкой HTML этого учебника. Проверка в двух размерах экрана относится к документу, а не к учебному frontend-приложению.

## Дополнение: сайт и новые возможности

Для сайта добавлены метаданные меню и конфигурация GitHub Pages с темой Just the Docs v0.12.0. Проверочная сборка завершилась успешно; в браузере проверены главная и переход к маршруту чтения. Новые страницы `updates/` сверены по текущим официальным источникам от 24 октября 2026 года. Действия `/side`, `/fork`, работа dot и Composer Predictions в пользовательском аккаунте при этом не выполнялись.

Свежие X-публикации Tibo возвращали 403. Содержание недоступных постов не используется как подтверждённое описание возможностей; срез релизов основан на официальном changelog. Это не полный ежедневный архив Tibo и не автоматический мониторинг.

## Как продолжить обучение

Редакция готова для чтения и самостоятельной практики. Можно начать с теоретических разборов, затем вернуться к быстрому старту и одному backend-упражнению. При обновлении Codex нужно повторно сверить изменившиеся команды и конфигурацию с официальными источниками; дата этой редакции не является обещанием актуальности будущих версий.


## Проверка перед публикацией на GitHub

Модули и приложения разнесены по самостоятельным Markdown-файлам. Добавлены переходы между модулями, порядок внесения изменений и журнал редакций. Ссылки на локальные файлы компьютера и дублирующие собранные HTML/Markdown исключены. Синтаксис PowerShell-примеров при разнесении не изменялся. Исторические проверки выше относятся к редакции от 24 октября 2026 года, а не к любым будущим коммитам.

## Дополнение: практическое использование из AI-радара

Отбор выполнен 24 октября 2026 года: просмотрены 155 результатов поиска `codex`, выделены семь разных задач. Прочитаны публичные источники выбранных сценариев и страницы OpenAI о браузере, изображениях и skills, а также официальная инструкция Figma MCP. Проверено ограничение Codex Slides: текущий экспорт PPTX содержит изображения, редактируемые текстовые и векторные объекты указаны в планах.

Практические промпты — учебные адаптации. Расширения не устанавливались, Figma не подключалась, модельные сценарии, генерация палитры, слайдов, схем и документов не запускались. Проверка PowerShell означает синтаксический разбор, а не выполнение Python-генератора. Публичный раздел не содержит экспорт радара, личные заметки или служебные адреса.

Проверены метаданные и закрытие кодовых блоков 32 Markdown-страниц, 187 локальных ссылок и используемые якоря: ошибок нет. У семи сценариев есть семь вариантов чтения без запуска. Новый PowerShell-блок разобран парсером PowerShell 7.6.5 без ошибок и не выполнялся. Независимая вычитка не выявила существенных повторов с существующими сценариями и модулем skills или неподтверждённых обещаний в новом блоке. В реестр добавлены девять снимков с SHA-256; Figma MCP дополнительно проверен по официальной веб-странице.

Следующий шаг: публикация через Pull Request, проверка сборки GitHub Pages и доступности нового блока. Проверка содержимого выше не заменяет проверку уже опубликованных страниц.
