# Что нового в Codex: проверенный срез

Состояние на **26 октября 2026 года**. Это выборка полезных возможностей, а не полный список релизов или публикаций Tibo. «Подтверждено» здесь означает подтверждение официальным источником; доступность вашему аккаунту и запуск на вашем компьютере проверяются отдельно.

## 26 октября: GPT-6.1 Terra для работы с изображениями и приложениями

В [официальном обзоре недели 26–30 октября](https://learn.chatgpt.com/docs/whats-new/october-26-30-2026) объявлена GPT-6.1 Terra для Codex и ChatGPT Work на Plus, Pro, Business, Enterprise и Edu. OpenAI предлагает её для понимания изображений и действий в поддерживаемых приложениях. В desktop откройте **Advanced** у выбора модели и выберите Terra, если она доступна вашему аккаунту.

Согласно [справочнику моделей](https://learn.chatgpt.com/docs/models), CLI требует версии **0.159.0 или новее**; идентификатор — `gpt-6.1-terra`, пример выбора — `codex -m gpt-6.1-terra`. Это пример для самостоятельного запуска в PowerShell, а не команда проверки без обращения к модели. Ранее проверявшийся в руководстве CLI 0.144.5 этому условию не соответствует; обновление здесь не выполнялось.

Ограничения: модель не доступна в обычном Chat; Enterprise зависит от настроек организации; UAE inference residency не поддерживается. Выбор Terra сам по себе не подключает браузер, desktop-инструменты или аккаунты. Их доступ и настройка проверяются отдельно, в том числе на Windows. Документация не подтверждает доступность в конкретном аккаунте читателя.

**Прочитать без практики:** представьте два скриншота BI-дашборда. Попросите сравнить одинаковый период, подписанные показатели и единицы, а нечитаемые значения отметить как неопределённые. Хороший разбор отделяет видимые изменения от предположений об их причинах. Запуск примера в модели при подготовке страницы не выполнялся.

Для проверки интерфейса используйте существующий [визуальный сценарий](../practice/index.md#visual-loop): смена модели дополняет его, отдельный повтор того же задания не нужен.

## Последний стабильный релиз CLI: 0.164.0 от 23 октября

| Изменение | Для чего полезно | Граница применимости |
|---|---|---|
| Десять нумерованных слотов `/presets` для запросов и slash-команд | Повторять короткие рабочие заготовки | CLI 0.164.0; точный синтаксис управления слотами сверяйте в клиенте |
| Inline-аргументы `/model` и `/permissions` | Быстрее выбирать параметры модели и разрешений | CLI; не переносить синтаксис на desktop без проверки |
| Изображения в полноэкранной истории | Смотреть полученные и созданные изображения в терминале | Требуется поддержка Kitty или Sixel; не любой Windows-терминал |
| Исправлено возобновление сжатой истории и сохранённых настроек чата | Надёжнее возвращаться к долгой работе | Не означает бесконечную память или перенос всей истории в активный контекст |
| Исправлена обработка Windows proxy authentication для HTTPS/WebSocket | Работа в средах с соответствующим прокси | Зависит от настройки организации; не повод менять защиту компьютера |

Источник всех строк: [официальный changelog, запись Codex CLI 0.164.0 от 23 октября](https://learn.chatgpt.com/docs/changelog).

На ноутбуке при подготовке базового руководства проверялся CLI **0.144.5**. Новые пункты выше в нём не запускались. Ради этой статьи Codex не обновлялся. Номер версии приложения desktop и версия CLI — разные сведения.

## Подсказки следующего сообщения — Composer Predictions

После ответа Codex приложение может предложить следующий запрос. **Tab** принимает подсказку как редактируемый черновик; отправка остаётся отдельным действием. Прочитайте текст: он не должен случайно расширять задачу.

По текущей документации это beta для пользователей 18+ с личным Pro в поддерживаемых регионах, для локальных и SSH-чатов с GPT-6 Astra и GPT-6.1 Sol. Переключатель — **Settings → General → Composer → Show predictions**. Подсказки используют контекст текущего чата; они сами не выполняют поиск по приложениям и памяти. Источник: [Composer Predictions](https://learn.chatgpt.com/docs/features/composer-predictions).

## Как читать очередной анонс

1. Найдите первичный пост или официальную запись релиза.
2. Уточните клиент: desktop, CLI, IDE, mobile, cloud или dot.
3. Проверьте версию, регион, тариф и ограничения организации.
4. Сначала попробуйте ограниченный сценарий, если окружение доступно.
5. Зафиксируйте результат отдельно от ожиданий автора анонса.

Для обновлений этого раздела используйте [правила внесения правок](../CONTRIBUTING.md). Текст анонса, доступность аккаунту и личный успешный запуск — три разных основания. Непрочитанный пост или пересказ неофициального трекера не становится подтверждённой инструкцией.
